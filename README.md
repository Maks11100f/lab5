## Структура

- `compute.h/.cpp` — `slow`, `quick` та універсальна `compute(name, duration)`; вивід через `osyncstream`
- `timing.h` — `timeit`, час виконання в секундах
- `work.h/.cpp` — `sequential::work()` та `parallel::work()`
- `main.cpp` — запуск
